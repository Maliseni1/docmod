# DocMod frontend

Vite + React app. See the [root README](../README.md) for the full
project overview, architecture, and deployment notes.

## Color system
Brand accent: **#B9491F** (terracotta), on warm paper/ink neutrals — see
`src/index.css` for the full token set (`--paper`, `--ink`, `--accent`,
etc.).

## Setup
```bash
cp .env.example .env   # VITE_API_URL, defaults to http://localhost:3000/api
npm install
npm run dev             # http://localhost:5173
```
